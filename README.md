## kovi-bot

### 杀戮尖塔 2 更新提醒

`kovi-plugin-sts2-update` 定时读取 Steam 官方公告，将新补丁翻译、整理成中文后推送到已订阅的 QQ 群。支持正式分支、Beta 分支或全部更新。

群命令：

- `尖塔2订阅 [全部/正式版/测试版]`：开启或修改本群订阅，仅群主、群管理员或机器人管理员可用。
- `尖塔2取消订阅`：关闭本群订阅。
- `尖塔2最新 [全部/正式版/测试版]`：立即查看最新补丁的中文内容。
- `尖塔2状态`：查看本群订阅状态。
- `尖塔2帮助`：查看命令说明。

插件首次启动后会生成 `data/kovi-plugin-sts2-update/config.toml`。默认每五分钟检查一次，翻译配置复用 `data/kovi-plugin-ai/config.toml`；翻译接口不可用时仍会推送英文内容和原文链接。订阅状态、公告去重记录和翻译缓存保存在插件自己的 `state.json` 中。
